# DX日曆 Chrome 擴充功能 (Manifest V3) — 電腦端跨系統伴侶版

本資料夾為 **DX日曆 (`DX-Calendar`)** 官方 **Chrome / Edge / Brave 擴充功能**（一次開發跨 **Windows / macOS / Linux / Chromebook** 通用），完整延續 Android `v2.0.0` 的金色美學與核心引擎。

## ✨ 核心功能
- **奢華金色亮暗自動主題**：跟隨系統自動切換「金色白底／金色黑底」（亦支援手動一鍵切換）。
- **工具列動態日期徽章 ＋ 雙形態顯示**：工具列金色徽章即時顯示當天日期；支援點擊彈出視窗（Popup）或一鍵開啟 **Chrome 側邊欄（Side Panel）**。
- **1900–2100 精準農曆、二十四節氣與台灣節慶** ＋ **7 天月曆天氣預報**（Open-Meteo 免費直連）。
- **100% 離線自然語言＋語音快速建行程**（0 費用免 LLM API），支援農曆初一十五、農曆每月、農曆每年、隔 N 週重複與倒數日。
- **輪班／常用範本連點排班 (Stamp Mode)**、**倒數日一覽**、**待辦清單**與 **🍅 番茄鐘專注計時（完成發送系統桌面通知）**。
- **與 Android DX日曆 v2.0.0 100% 備份互通**：支援匯入／匯出相同結構之 `.dxbackup.json`（自訂裝置名稱寫入檔名），搭配 Google 雲端硬碟實現 0 伺服器費用跨系統同步！

## 🚀 10 秒本機安裝測試（Chrome / Edge）
1. 在 Chrome 位址列輸入 `chrome://extensions/`（Edge 輸入 `edge://extensions/`）。
2. 開啟右上角 **「開發人員模式 (Developer mode)」**。
3. 點擊左上角 **「載入未封裝項目 (Load unpacked)」**，選取本專案的 `chrome-extension` 資料夾即可立即使用！
4. 建議點擊瀏覽器右上角拼圖圖示將 **DX日曆** 釘選至工具列，即可隨時看到當日日期徽章並點擊展開月曆或側邊欄。
