核心特色 / Key Features

  • 奢華金白／金色黑底雙主題與 1–31 動態日期圖示 — 自動跟隨系統深淺模式與午夜跨日刷新。
  • 100% 離線自然語言與語音快速建行程 — 免外接 AI 費用、零延遲解析時間、重複與提醒。
  • 5 款高解析透明含天氣桌面小工具 — DX 月曆 (60fps 展開週＋now)、DX 時間表 (now)、下一行程 (4×1)、倒數日 (2×2)、單週 7 天天氣 (4×2)。
  • Google 行事曆與 Google Tasks 整合 — 即時同步呈現您的 Google 行事曆與 Google Tasks 待辦事項於月曆、時間軸與桌面小工具。
  • 農曆初一十五與聯絡人生日算歲數 — 支援 1900–2100 農曆節氣、農曆每月／初一十五／農曆每年重複與聯絡人生日自動匯入。
  • 輪班範本連點排班、雙時區時間軸、番茄鐘、協作留言與雙指紋隱私日曆 — 採 Android Keystore AES-256-GCM 硬體加密與無損 Google 雲端硬碟跨裝置備份。

Google API 使用說明 / Google User Data Transparency

DX日曆僅於使用者主動連結 Google 帳號並明確授權後，透過 Google Tasks API 讀取並同步顯示您的 Google Tasks 任務至本機日曆與桌面小工具，並於您勾選任務完成時同步更新任務完成狀態。所有資料僅儲存於您的本機裝置，開發者不架設任何中繼伺服器，亦不蒐集、販售或向第三方分享任何個人資料。詳見 隱私權政策 (Privacy Policy)。
