🇹🇼 繁體中文隱私權政策

感謝您使用 DX日曆 (DX-Calendar，套件名稱 com.dx.calendar) 與官方 Chrome 擴充功能。我們高度重視您的個人隱私，DX日曆採「純本機優先、無廣告、無中繼伺服器」架構設計。

  • Google Tasks API 資料存取與用途：僅在您於「設定 → 行事曆與 Google Tasks」主動選擇 Gmail 帳號並授予 Google OAuth 授權（範圍：https://www.googleapis.com/auth/tasks）後，本應用程式才會直接從您的裝置連線至 Google 官方伺服器，讀取您的 Google Tasks 清單與任務並呈現於月曆、時間表與桌面小工具中；當您於日曆中勾選任務完成狀態時，僅將完成狀態同步回 Google Tasks。
  • Google API 有限使用規範 (Limited Use)：DX日曆對於自 Google API 取得之資訊的使用與傳輸，均嚴格遵守 Google API Services User Data Policy（包含 Limited Use 限制使用條款）。我們絕不將您的 Google 資料用於廣告投放、使用者側寫、AI/ML 模型訓練，亦絕不販售或提供給任何第三方。
  • 其他裝置權限說明：
    • 行事曆 (READ/WRITE_CALENDAR)：僅於本機讀取與編輯您裝置上的系統／Google 行事曆。
    • 聯絡人 (READ_CONTACTS，可選)：僅於您主動點擊「匯入聯絡人生日」時於本機讀取生日日期以計算倒數與歲數，資料完全留存於裝置本機。
    • 生物辨識 (BIOMETRIC)：僅供「隱私日曆」本機解鎖使用，敏感內容以 Android Keystore AES-256-GCM 硬體加密儲存於本機。
    • 網路 (INTERNET)：用於同步您主動授權之 Google Tasks、取得免定位權限之 Open-Meteo 7 天天氣預報（依系統時區對應城市座標），以及檢查 GitHub 新版更新。
  • 資料保存、刪除與撤銷授權：所有本機行程、備份檔與設定皆存於您的裝置中（若您使用備份功能上傳至您的 Google 雲端硬碟，亦完全存放於您個人雲端硬碟）。您隨時可於 App 內刪除資料、解除安裝應用程式，或前往 Google 帳戶權限管理頁面 一鍵撤銷 DX日曆對 Google Tasks 的存取授權。

🇺🇸 English Privacy Policy

DX-Calendar (Android package com.dx.calendar and its companion Chrome Extension) is designed with a strict local-first, ad-free, zero-backend-server architecture.

  • Google User Data & Google Tasks API: Only when you explicitly select a Google account and grant OAuth consent (scope: https://www.googleapis.com/auth/tasks) does DX-Calendar communicate directly between your device and Google's official API servers to fetch your Google Tasks lists and tasks for display in your calendar views and home screen widgets, and to sync task completion checkboxes when you toggle them.
  • Google API Services User Data Policy (Limited Use): DX-Calendar's use and transfer to any other app of information received from Google APIs strictly adhere to the Google API Services User Data Policy, including the Limited Use requirements. We do not operate any developer backend server, do not sell or share your data with third parties, do not use your data for advertising, and do not use Google user data to train AI/ML models.
  • Optional Device Permissions:
    • Calendar (READ/WRITE_CALENDAR): Used solely on-device to display and edit calendars stored in Android CalendarProvider.
    • Contacts (READ_CONTACTS, optional): Used strictly on-device when you tap "Import Contact Birthdays" to read birthday dates and calculate countdowns/ages locally.
    • Biometrics: Used exclusively on-device to unlock the AES-256-GCM hardware-encrypted Privacy Calendar.
    • Internet: Used for user-authorized Google Tasks sync, timezone-based 7-day weather via Open-Meteo (without requesting GPS location), and GitHub update checks.
  • Data Retention, Deletion & Revocation: All app data stays locally on your device (and any backups you export to your personal Google Drive stay solely under your own Google account). You can delete local data anytime inside the app or by uninstalling, and revoke Google Tasks access anytime at Google Account Permissions.
  • Contact: For any privacy inquiries, contact dx9901mk5@gmail.com.
